
A command-line program for managing a small library, written in C++17. Books are stored in a text file, so your data is still there the next time you run it.

Here is what you can do:

1) Add and remove books
2) Search by title or author (case-insensitive)
3) Borrow and return books, with the borrower's name recorded
4) Sort the list by title, author, or year
5) Statistics: totals, borrowed/available counts, most common author, oldest and newest book
6) Automatic saving to books.txt after every change
7) Sample data option to try it out quickly

Here is how you use it:
The program basically shows a numbered menu and you have to type a number and press enter based on the action you want to commit. 
Here are all the options:
1	List all books
2	Add a book
3	Remove a book by ID
4	Search by title or author
5	Borrow a book
6	Return a book
7	Sort the list
8	Show statistics
9	Load sample data
0	Exit
